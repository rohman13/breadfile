# BreadFile Code of Conduct

## Our pledge

We want BreadFile's community to be welcoming, respectful, and safe for everyone, regardless of background, identity, experience, or ability.

## Expected behavior

- Be respectful and constructive.
- Assume good intent while discussing ideas and code.
- Accept useful feedback gracefully.
- Focus criticism on the work, not the person.
- Respect privacy. Never publish another person's personal information or confidential documents.

## Unacceptable behavior

- Harassment, threats, discrimination, or personal attacks
- Sexualized language or unwanted attention
- Trolling or intentionally disruptive conduct
- Publishing private information without permission
- Any conduct that would be inappropriate in a professional community

## Enforcement

Maintainers may edit or remove comments, issues, pull requests, or other contributions that violate this Code of Conduct. Repeated or serious violations may result in a temporary or permanent ban from project spaces.

Report conduct concerns privately through the repository owner's GitHub profile. Security vulnerabilities should use GitHub's private vulnerability reporting feature rather than public issues.

## Scope

This Code of Conduct applies in BreadFile's repository, issue tracker, pull requests, discussions, and other spaces where someone is representing the project.
